# LiveSplit To Youtube Chapters
Allows uploading [LiveSplit](https://livesplit.org/) .LSS files and converting them into chapters for a YouTube video description

All processing happens inside your browser, no data is sent off the machine.
[Open LiveSplit2YouTube](https://budditec.nz/livesplit-to-youtube-chapters/)

## Usage

1. Use the file picker to find your .lss file and load it.
2. Pick the run you want to generate chapters for. You can optionally show/hide DNF runs.
3. Enter the name for the Start/Intro timestamp of your video.
4. You can use the **Offset** box if your video start doesn't line up with your LiveSplit run.
5. Copy the **YouTube Chapters** section and paste it into your YouTube video description.
6. Optionally check the **Show Attribution** box to include a link back to this tool in your output.
